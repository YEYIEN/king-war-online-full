## 二、V2 UI 程式變更

在 `server/v2-playtest.html` 新增畫面內 **可視化抽牌／棄牌**操作：

1. 點擊「可視化抽牌／棄牌」後，向伺服器發送 `v2:preview-end`，讀取權威的手牌及待抽牌資料；
2. 秦始皇玩家先從新抽三張牌中點選一張放回牌庫底部；
3. 以實際可點選卡片選擇**剛好**超過手牌上限的棄牌數，畫面顯示已選數量；
4. 確認後送出 `v2:end`，仍由伺服器驗證選擇與執行回合輪轉；
5. 可取消選擇；新房間狀態到達時清除舊的選擇面板以避免陳舊操作。

**向後相容：** 暫時保留舊的「結束回合」瀏覽器原生 prompt 操作路徑，以免既有完整對局回歸失去基線。**所以目前不能宣稱「無 prompt 的完整 UI 已完成」**，下一次需整合新 UI 為唯一流程、逐步移除舊入口。
