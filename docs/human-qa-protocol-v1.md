# 《國王戰爭》P6 真人封閉測試手冊（待執行）

本文件是**可直接操作的測試計畫**，並非已實際招募或完成真人測試的報告。測試必須經遊戲所有者確認招募及資料告知安排。

## 目標和抽樣

第一輪建議 30～50名、涵蓋：從未玩過本遊戲、有桌遊經驗、熟悉策略遊戲的玩家；桌機／手機、不同網路環境；以2、3、4、5人對局各取樣。此規模只能做**形成性使用性測試**，不能精確推估五王全部配對勝率。

## 測試時不能做的事

- 正常比賽不顯示或提供決策答案，不替玩家出牌或強制選擇策略。
- 研究員只負責說明怎麼進入遊戲、如何回報問題、資料使用及退出權利。
- 新手教學如有使用，必須記錄它是玩家主動選擇，並與直接入場玩家分開分析。
- 不收集隱藏手牌／個人身分以外的多餘資料；不在沒有適當告知時錄影或擷取玩家畫面。

## 測試任務

| 任務 | 觀測內容 | 成功條件 |
|---|---|---|
| T1 首次進入 | 開始遊戲、建立／加入房間 | 獨立完成，沒有阻斷錯誤 |
| T2 完成對局 | 操作和戰鬥、魔法流程 | 能正確完成一局或說明放棄原因 |
| T3 桌機與手機 | 能辨識 HP、可行動兵種、攻擊與魔法目標 | 重要資訊沒有不可讀或超出畫面 |
| T4 斷網重連 | 短暫斷線、重新整理或瀏覽器切換 | 能用合法憑證回復，公開與私人資訊一致 |
| T5 不同 AI 難度 | 簡單、中等、困難、征服者 | 測量錯誤操作、勝率與策略應用，不直接宣稱能力改善 |
| T6 多人混戰 | 3～5人輪到不同位置 | 角色辨識、等待、目標選擇與回合長度合理 |
| T7 劣勢局面 | 自然遇到嚴重危機 | 觀察是否仍有玩家認為有價值的反制手段 |

## 收集指標與定義

1. `firstGameCompletion`：首次進場者有完成對局／首次進場者數；另報告放棄原因，不能只看勝率。
2. `taskSuccess`：指定操作獨立完成次數／嘗試次數；需保留失敗的具體 UI 步驟。
3. `unexpectedAction`：誤按導致與預期不同的合法操作／所有相關操作；訪談才能判定是否為誤按。
4. `reconnectSuccess`：在定義的60秒窗口內成功回復的中斷情境／全部符合條件的中斷情境。
5. `turnTime`：玩家實際操作秒數的中位數及P90，不直接使用 AI 模擬回合數推定。
6. `kingWinRate`：每位國王成功勝場／該王完賽參賽場次，依玩家經驗與遊玩人數分層。
7. `severeComeback`：依既有遊戲規則定義的危機局數與後續逆轉，不把「使用救援技能」自動當作逆轉成功。
8. `retentionIntent`：玩家是否願意再次玩及原因；意願不等於實際留存，需後續實際回訪數據。

## 判斷與報告

每次重大 UI 問題，應提供畫面、重現步驟、裝置及系統、嚴重度、受影響玩家數與修復後複測；**不要把研究團隊的主觀印象當實測結論**。

建議首次體驗完成率、基本操作成功率、斷線成功率及對局時長依 P6 需求設定初始門檻；達不到者返回 P1／P3／P5 修正。不強迫所有玩家給同一個答案。

未有本次測試的實際受試者、研究告知／同意及真人對局資料；因此本階段只完成**可執行的測試設計、資料規格及自動化冒煙測試**，沒有通過真正的玩家研究驗收。
