# 國王戰爭｜正式發行優化計畫 v1
更新：2026-11-19。正式來源：YEYIEN/king-war-online-full，main。發行目標：Google Play、Steam。原則：先穩定網頁核心，再封裝；不影響既有玩家的對局資料；任何需付費資源先取得同意。

## 發行準則（Definition of Done）
- P0 阻擋發行：手機或桌面遊戲凍結、崩潰；非法操作／玩家身分冒用；手牌或重連憑證洩漏；無法完成對局；服務重啟遺失進行中對局；平台要求的隱私、帳號刪除、安裝與政策不合規。
- P1 發行前完成：遊戲說明一致、陌生玩家能完成教學、卡牌可辨識、完整錯誤紀錄、先後手及國王平衡驗證、基本無障礙。
- P2 發行後可做：成就、排行榜、好友、賽季、外觀解鎖。不得以 P2 延誤 P0。
- 「程式存在」不等於「驗收通過」；每項需保留測試證據、日期、版本與責任人。
