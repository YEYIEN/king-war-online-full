# 《國王戰爭》全面沙盤推演：平衡問題、解釋與候選方案（研究版）

**日期：2026-11-15**  
**測試基準：Draft PR #7 `feature/prebalance-hardening-ai-20261114`；非正式 Render/main。**  
**原則：本輪研究可以開啟既有實驗旗標，但不修改正式遊戲的國王、牌組及卡牌數值。**

> 此報告分成**已驗證的歷史觀察**、**待本輪32情境研究檢驗的假設**、**候選解法**。研究結果未取得前，不把候選解法宣稱為有效平衡修正。

## 1. 研究方法與可重跑資料

- **研究工具**：`scripts/balance-factorial-research.mjs`、`scripts/balance-factorial-analysis.mjs`。
- **對戰引擎**：`server/index.js` 的 `simulateKingBaseline`，執行正式伺服器遊戲規則及 AI 決策；不是完整對手資訊集合推理／真人賽局。
- **矩陣**：32情境，3個探索種子 `701921`、`802403`、`903617`，每個情境每種子250局，預定共24,000局。
- **模式**：2–5人；normal、hard、conqueror；征服者挑戰困難 AI；雙人先手休戰及後手+1張牌的單獨／聯合研究；路易十四法師策略；多人魔法最佳目標策略；背水一戰開關與防禦旗標。
- **匿名逐局紀錄**：國王、座位、初始手牌的兵種及階級數量（不是牌 ID 或牌序）、AI難度、勝負、局長、攻擊／施法總數、翻盤資格、能力使用次數。
- **彙總數據**：國王×情境／座位×情境勝率、Wilson 95%區間、未完成數、翻盤率、戰鬥及魔法使用、研究策略差異。
- **歸因注意事項**：相同種子不保證不同條件走相同亂數序列。條件與結果關聯不是隨機化的因果效應，須在未使用的 holdout 種子驗證。獨立假設檢定也應注意多重比較。
- **產物**：`balance-factorial-raw.json`、`balance-factorial-summary.md`、`balance-factorial-analysis.json`、`balance-factorial-analysis.md`，由 GitHub Actions 附上。

## 3. 按證據強度排列的平衡問題及修正候選

### P0 — 雙人先手偏差

- **因果假設**：較早部署／攻擊與先達到戰鬥門檻造成累積優勢；後手抽牌差異可能緩解。
- **本輪研究**：hard 和 conqueror 分別測 (A)原制、(B)首回合先手休戰、(C)後手補1牌、(D)兩者合併。
- **候選**：採最低成本且跨 hard/conqueror 都有效的方案，預設先選「先手首輪禁止攻擊」或「後手補牌」之一；合併方案須有額外必要性證據。
- **放行門檻**：探索期朝45–55%靠攏、不能增加明顯未完成率、不得令任何國王×座位格子有極端反效果。每一個座位×國王配對需增加到有足夠樣本後才選擇。
- **副作用**：弱化騎兵立即攻擊特色、影響快攻與慢局比例、成吉思汗或秦始皇拿到補牌可能改變既有強度。

### P0 — 五人局大劣勢難翻盤

- **因果假設**：保護王與補牌不足以支撐反擊，或者 AI 未正確使用背水一戰；不能直接判斷盾值太低。
- **本輪研究**：hard/conqueror 的原制、關閉背水一戰、已有防禦反擊候選旗標，追蹤危機資格及實際使用、平均局長。
- **候選順序**：先修 AI 對「該何時使用背水」的策略；若最佳策略仍無法翻盤，再測一次性-2→-1 HP 成本、護盾壽命或防禦反擊（每次只改一項）。
- **放行門檻**：探索階段可把嚴格危機翻盤率>=3%作為研究參考，而非所有局都要達成的公平標準；須同時確認非危機玩家不被不合理懲罰。
- **副作用**：拖延戰局、重複觸發、刻意壓低血量騙取補助、削弱領先者的有效策略。

### P0 — 路易十四的多人法師資源鏈

- **因果假設**：AI 太少部署／保護法師，導致國王被動無法啟動；不能先把問題歸咎國王數值。
- **本輪研究**：四／五人 normal 的現行策略與 `louisMageSetup=true` 實驗；另檢查 `aiMagicTargeting=true` 是否出現負面副作用。
- **候選順序**：部署法師優先、保護法師與延遲決策的搜尋策略；若 AI 改善後強策略對局仍有穩定落差，再研究有限額外魔法啟動保障。
- **放行門檻**：四人探索候選路易十四>=17% 作為先達標研究門檻；多人各人數及其他國王不能明顯退化；最終需要獨立 holdout。
- **副作用**：魔法手牌資源形成爆發式優勢、法師卡隨機分配更有決定性、AI 過度保護法師而放棄其他戰術。

### P1 — 成吉思汗及秦始皇的資源優勢風險

- **證據**：五人 normal 成吉思汗29.17%；秦始皇每回合2抽及高牌手上限有潛在持續資源優勢，但未確認過強。
- **研究**：國王×座位×AI難度分層；估計起手騎兵、額外抽卡及撤回的實際勝率關聯。
- **候選**：成吉思汗撤回抽牌限額或次數、秦始皇手牌上限／抽牌速度**僅列為備案**。未有跨難度異常與真人遊戲證據，暫不調數值。
- **副作用**：削弱國王特色、變成僅靠運氣的被動、讓一個問題轉移到另一國王。

### P1 — 多人目標選擇與魔法效率

- **假設**：AI 在多人局挑選敵人、魔法時機不合理，導致局面或國王勝率偏差，而非魔法數值失衡。
- **研究**：比較目標搜尋 A/B 的四五人對局，並留意回合長度、翻盤下降及路易十四的負效應。
- **候選**：先提升選敵／施法策略，補充「清除最後步兵→後續王傷」統計後才考慮調整魔法威力。
- **副作用**：多人玩家集火、強者針對強者而令戰局被動、降低策略多樣性。

### P1 — 抽牌與開局兵種組合

- **假設**：起手擁有步兵防線、騎兵速攻或法師引擎的差異，可能放大先後手／國王差距。
- **研究**：固定情境、國王、座位後，觀察起手有無步兵／騎兵／法師／高級兵種的勝率差；仍是觀察性研究。
- **候選**：只在多種 AI 與獨立種子都穩定過度影響勝負時，研究可選的起手換牌機制或初始手牌保障，而非先改整個牌堆配比。
- **副作用**：增加每回合操作成本、減少牌組差異、引入新的可利用起手最佳化行為。

### P2 — 長局與低互動回合

- **證據**：五人 easy 舊版平均60.23個玩家行動回合，並非60分鐘。
- **候選**：改良後期資源耗盡與膠著局的處理；必要時研究回合上限、抽牌資源循環，但不能僅因某種難度局長長就改規則。
- **副作用**：傷害慢速防守策略、迫使國王能力趨同或提高隨機終結性。

## 4. 方案取捨與驗收

1. **先把 AI 問題與數值問題分離**：正常/困難/征服者在同樣規則下差異，能幫助區分「不會玩」與「角色真的弱」。
2. **候選先以已存在的研究旗標對照**：沒有獨立證據時不新增第二個同時改變多變數的版本。
3. **不能只看單指標**：勝率之外要檢查座位×國王、危機翻盤、局長、低互動機率、魔法佔比及實際資源運用。
4. **樣本門檻**：探索每組至少600局；準正式候選每組>=3000局，並使用完全不同的 holdout 種子；所有控制/候選逐人數分層。
5. **研究中的不變量**：所有 AI 使用合法規則、沒有額外獎勵；伺服器 invariant 違規為0；逐局私人卡牌及連線資料不得外流。
6. **人工驗收**：正式發布前需真人盲測，不能把 bot 對 bot 勝率當作玩家感受的全部。

### 6.2 對候選方案的實際判定

1. **先手限制攻擊是有方向性改善的候選，但仍不足以結案**：hard先手-6.80百分點（探索性約95%差異區間 -11.61至-1.99）；conqueror合併方案先手-5.73百分點（-10.66至-0.81），但未達45–55%研究目標。
2. **單純給後手+1牌沒有穩健改善證據**：hard及conqueror單獨補牌差異區間均跨0。
3. **路易十四目前兩個AI候選應保留預設關閉**：四人法師部署加18分後勝率反而下降；五人未見足以驗證的改善。
4. **固守反擊候選暫不採用**：五人 hard/conqueror 與對照組全數值相同，必須查實際觸發／反擊收益，而不能宣稱成功增強逆轉。
5. **最值得優先做策略因果分離的是成吉思汗**：四／五人 conqueror 勝率極高，但五人 hard只有17.73%；若未排除AI特殊策略的作用就直接砍其能力，很可能破壞較低難度及雙人模式。
6. **開局卡牌組合不是目前最有證據的數值問題**：起手高級兵種在混合模式的分層觀察效應接近零，不支持立即改牌庫階級配比。

### 6.3 下一步放行條件

仍需用未參與篩選的種子、每候選至少3,000局，驗證先手候選與國王策略方案。對成吉思汗須先拆解撤回騎兵與補牌的收益，對路易十四須追蹤法師存活及施法後的有效王傷；不能單從勝率推斷能力數值需要改動。正式主分支與 Render 仍未修改。
