# 國王戰爭 V2｜第三周目規則基準與 UI 方向（工作版）
更新：2026-11-21。此文件以本專案近期已確認的 V2 對話規則為準；較早《完善版規則書 v1.0》屬歷史參考，不作為 V2 執行規則。

## 一、目前確立的 V2 基準
- 2–5 人；每名國王 24 HP；最後存活者獲勝。
- 主牌 60 張；步兵、刺客、魔法師、騎兵各 15 張（初級 7、中級 5、高級 3）。目前程式內部代碼「弓兵」對應刺客、「法師」對應魔法師；此為技術別名，正式 UI 應顯示新名稱。
- 克制：步兵 > 刺客 > 魔法師 > 騎兵 > 步兵；克制時戰力 +1。
- 起手 5 張、手牌上限 5、場上最多 3 名；新部署不能立即攻擊；每回合結束抽 2 張，超過上限時由玩家選擇棄牌；不能主動棄牌。
- 直接攻擊國王時，場上步兵可防守，刺客可繞過。保牌依不同攻擊玩家各有一次機會，守方自手牌出牌；防守戰力大於等於攻擊戰力則擊殺攻擊單位且不扣 HP，否則國王受傷害減 1。
- 九種魔法由魔法師選擇施放，**沒有獨立魔法牌庫或魔法手牌**；魔法師階級限制可施放魔法級別，魔法師施法消耗行動；同一玩家每回合最多施放一次。
- 五位國王：亞歷山大、屋大維、成吉思汗、秦始皇、路易十四。秦始皇抽 3 張並從新抽 3 張中放 1 張回牌庫底；路易十四犧牲回合開始時已在場上的單位回復 3 HP（上限 24）。

## 三、第三周目驗收門檻
1. 核心與多人測試實際執行並保存日誌。
2. 2、3、4、5 人對局均能從建房到勝者產生；不洩漏他人手牌。
3. 確認國王、魔法、部署、保牌、回合、棄牌與斷線處理。
4. V2 取代正式入口之前，V1 必須保持可回復。
5. 未驗收的功能明列，不以 commit 數量代替成果。

## 四、UI 與美術設計基準（第三周目定向）
**風格：** 日系二次元抽卡手遊立繪、半厚塗、柔和夢幻光影、帶光澤的皮膚、寶石質感眼睛、細膩飄逸髮絲、華麗蕾絲與裝飾、自然微紅臉頰、正視鏡頭。五位國王的性別表現與歷史元素尚未決策，不擅自將其全部改為同一種人物形象。

**介面層級：** 最重要的是回合玩家、生命值、手牌數量、可操作卡牌、可選敵人、魔法效果與防守回應。裝飾不得掩蓋資訊。

**第一個視覺樣板：** 一位國王的全身立繪＋國王選擇卡＋戰場上的國王資訊框，先確認角色和 UI 的一致性，再擴展其餘角色。

**技術資產規範：** 圖片使用具來源及授權記錄的檔案；介面圖示與遊戲規則文字不得烘焙進角色立繪；支援手機與桌面閱讀；提供圖片載入失敗時的文字備援。
