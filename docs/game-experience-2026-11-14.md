# 國王戰爭｜玩家體驗重設計與初步模擬報告

日期：2026-11-14。**此文件描述 feature 分支原型，不代表正式 main 或 Render 已部署。**

## 目的及關鍵判準

1. 新手：應在真實伺服器規則下作出「為何先強化再攻擊」的正確判斷，而非僅跟著固定動畫點擊。
2. AI：簡單以容錯選牌為主、中等用成本交換和威脅辨識、困難評估阻擋國王攻擊的守衛、致勝一擊、場面威脅及多個敵人的價值；困難仍是啟發式而非完整搜尋。
3. 國王：用真實的伺服器規則、可重現的 AI 對戰測量，不將結果視為真人勝率。
4. 逆轉：避免無條件補血或追平局勢，提供風險—回報決策，同時觀察先後手勝率與「使用後實際逆轉」的頻率。

## 實作原型

- 真實戰鬥引擎中的四階段教學：部署中級騎兵、施放力量術使 2 vs 2 成為 3 vs 2、擊敗中級弓兵、結束回合；錯誤順序由後端拒絕，完成後須回答因果理解題。
- 房主與單人模式均可選簡單、中等、困難。困難 AI 可在多位玩家之間分散評估，不再只打第一名敵人；考量最後一名步兵、致命傷害、法師及魔法威脅。成吉思汗 AI 開始使用撤回能力。
- 路易十四在有法師時增加魔法補充，第一次成功施法後抽兵種並使法師恢復一次行動；秦始皇保留每回合雙抽及手牌上限 9，但不再開局額外多拿一張；成吉思汗開局保證至少一張騎兵，額外抽牌限首次兩次有效撤回騎兵。
- 「背水一戰」實驗規則：HP 4–12、場上至多兩兵種、對手有明顯優勢，才可以每局一次花 2HP 換兩張兵種、緊急部署與限時最多 3 點國王護盾；護盾每次最多只能減傷到至少受到 1 點傷害，房主可關閉。
- 「開局全部先部署」試驗未顯示明確額外公平性，因此不在正式玩家設定中展示；測試旗標仍留供後續研究。

## 勝率的正確解讀

### 原始策略，最早的測試

固定種子、舊 AI，雙人 300 場與五人 150 場：

| 國王 | 雙人 | 五人 |
|---|---:|---:|
| 亞歷山大大帝 | 58.82% | 17.33% |
| 屋大維奧古斯都 | 55.56% | 24.00% |
| 成吉思汗 | 42.24% | 17.33% |
| 秦始皇 | 58.54% | 22.67% |
| 路易十四 | 35.20% | 18.67% |

初期 AI 預設鎖定第一名敵人導致嚴重位置偏差：五人局第四、第五席贏下全部場次，**不能據此斷定被動效果失衡大小**。

### 改良策略 + 調整被動的測試

固定種子、困難 AI、雙人 1200 場（此組為 2026-11-14 中途測試，非最後完整信賴區間分析）：

| 國王 | 勝率 |
|---|---:|
| 亞歷山大大帝 | 49.90% |
| 屋大維奧古斯都 | 48.52% |
| 成吉思汗 | 36.50% |
| 秦始皇 | 60.50% |
| 路易十四 | 54.40% |

該組雙人先手勝率約 64.33%，仍須調整。

500 場困難五人局，修正 AI 目標評估後，座位勝率約為 18%、18.4%、21.2%、21.6%、20.8%；但成吉思汗同一組仍約 42.2%，表示國王**尚未平衡**，不能直接把方案視為定案。

### 國王與逆轉機制 A/B 初步比較

- 路易十四：在 1800 場困難雙人測試中，首次施法不恢復法師行動時勝率 47.33%，恢復行動時 53.90%。有幫助，但兩個處理條件在施法後隨機流程可能分叉。
- 秦始皇：1800 場困難雙人，取消開局第六張兵種後約 61.29%，仍偏強。
- 成吉思汗：兩人局改動後仍偏弱（約 35–37%）；困難五人局偏強（約 42%），代表同一被動與模式/AI 強烈交互作用。
- 背水一戰：1600 場困難雙人中約 536 場有玩家使用；不含護盾時只有 52 場由使用者獲勝，加入 3 點護盾後為 57 場，改善很小，**目前尚未證明是有效的逆轉機制**。
- 開局公平性：雙人後手開局多 1 或 2 張手牌，先手勝率約由 64% 降至 60%，但仍非接近 50%；五人「每人先部署一回合」也未顯示明顯收益。

以上試驗的 AI 策略、卡牌分佈及對手目標選擇會影響數字；部分樣本數只有幾百。評估真人遊戲需要對手交換座位、多個隨機種子、不同策略類型與真實測試，不宜將 AI 勝率視為客觀「國王強度排名」。

## 後續建議

優先處理雙人先手優勢及成吉思汗在不同人數模式中的效果差異；考慮根據模式限制回收的資源價值，而非只把抽牌次數調低。逆轉機制宜用「啟動後該玩家最終翻盤的提升量」測量，同時追蹤遊戲長度、後手勝率及因補償造成的反向雪球。玩家體驗方面應再做首次教學操作成功率、教學後無引導獨立操作測試、真人手機觸控與可讀性驗收。

**正式版本維持不變，須等使用者審閱新規則並完成真實玩家測試後再考慮部署。**

## 第二輪迭代｜同日實驗追加

本節記錄 PR #5 後續檢驗（完整實驗 log 可見 GitHub Actions **Game balance simulation**）。下列勝率是 **AI 對 AI、伺服器規則、固定種子** 的結果；不是實際玩家統計、沒有表示因果作用一定會移轉到真人對戰。

### 雙人先後手：公平開局實驗

在困難 AI、雙人、1,800 場測試中：

| 方案 | 先手勝率 | 後手勝率 |
|---|---:|---:|
| 原基礎規則（無額外補償） | 約 64% | 約 36% |
| 後手多 1 張開局兵種 | 約 60% | 約 40% |
| 先手首回合不能進攻 | 約 59% | 約 41% |
| **兩者同時啟用** | **54.11%** | **45.89%** |

整體顯示「先手限制＋後手補牌」在模擬中效果較好，並已新增房主可切換的**雙人公平開局實驗規則**。預設維持關閉；這並非經真人證實的正式平衡調整，亦非所有 AI 策略下的 54% 保證。

### 五人局：成吉思汗與 AI 的威脅辨識

採用同一難度和樣本數（每組 1,200 場、所有五王各參賽 1,200 場），僅調整 AI 視成吉思汗為長期威脅的額外分數：

| 額外威脅權重（內部相對值） | 成吉思汗勝率 |
|---|---:|
| 0（無額外辨識） | 44.25% |
| 1（輕度） | 26.33% |
| **2（中度）** | **18.75%** |
| 3（偏重） | 12.75% |
| 過去的高強度方案 | 約 2.33% |

暫選權重 2。這凸顯了國王勝率與電腦對手選擇如何互相影響：**強化 AI 會改變模擬中其他國王的勝率，並不等於真正平衡了卡牌被動。**

### AI 魔法決策

困難 AI 開始評估魔法效益：火球術、流星雨優先考慮可直接消滅的初級單位；冰凍與虛弱考慮目標能否行動；我方增益盡量指定尚能攻擊的兵種。舊策略與新策略各 800 場五人困難對局：

- 舊策略的五王勝率：21.25%、22.50%、18.63%、17.38%、20.25%。
- 新策略的五王勝率：21.38%、24.50%、17.63%、14.88%、21.63%。
- 此結果顯示新 AI 沒有在這組測試中造成明顯座位偏差，但**尚不能判定它一定更接近人類認為的聰明操作**；應增加局勢決策案例測試。

### 「背水一戰」的二擇一

新版保留每局一次、消耗2HP、條件限制與實際承受至少1點傷害的護盾規則，改為：

- **突圍**：抽2兵種、下一張合格部署單位可立即行動，護盾3點。
- **固守**：抽1兵種、不額外獲得緊急部署，護盾7點。

在一組 1,600 場困難雙人對戰中，約 584 場有玩家觸發背水一戰，模式使用次數約突圍377次、固守219次（單場可能兩位玩家都使用，因此使用次數大於場次）。有護盾時，使用者最終獲勝約79場，未啟用護盾時約61場。這表示有一定提升，但**並沒有解決所有一面倒的對局**；後續應比較啟動時局勢相近的遊戲案例，而非只看所有使用者的最終勝率。

### 仍保留的開發風險

1. 兩人局的先手優勢在一般規則下仍存在；公平開局屬試驗開關。
2. 困難 AI 依然是啟發式策略，非完整的多回合遊戲樹搜尋。
3. 國王五人與二人局有強度交互作用，應分開評估，不應對所有人數硬套一個數值。
4. 用來比較各種設定的伺服器模擬已有可重現種子，但變更中途卡牌、抽牌會改變後續亂數呼叫，對照結果仍是**近似配對，而非嚴格共享所有隨機事件的因果模擬**。
5. GitHub CI 自動測試與瀏覽器尺寸模擬不等於真實多人操作。未合併 main、未更新 Render 正式服務。
