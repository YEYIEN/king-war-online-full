# 《國王戰爭》V2 第七周目｜第一次開發紀錄

**日期：** 2026-11-22（Asia/Taipei）  
**周目：** 第七周目 **1/5**；尚未結案；第 8 周目以驗收為主，但前提是第七周目 P0 功能凍結達成。  
**開發分支：** `rules-v2-tabletop-rebuild`；`main` 及正式 V1 未修改。

## 一、本次依最新 GitHub 實際修改

### A. 新版頁面內戰鬥／國王能力操作（P0 分段交付）

`server/v2-playtest.html` 新增 `#tactic-choice` 面板以及相對應的前端操作狀態：
- **普通兵種攻擊**：直接點選我方可行動兵種 → 對手玩家 → 對手場上兵種或國王 → 確認。多人的目標由伺服器名單呈現，不再需要輸入索引號。
- **亞歷山大**：攻擊敵方兵種時，可在面板內勾選本次 +1 戰力；不得用於國王直擊。
- **成吉思汗**：選一名我方場上兵種和一張我方手牌，按確認執行交換。
- **路易十四**：點選場上兵種，按確認執行犧牲。
- 所有指令仍送給原有 `v2:attack`／`v2:ability`，**合法性由伺服器權威判定**；前端只負責可點選的展示和選擇。
- 暫保留**舊版直接按鈕／原生 prompt**（供既有回歸使用）。因此「全面無 prompt UI」尚未完成，不能冒充整體 UI 已升級。

修改提交：
- `0b6abbe8`：戰術選擇面板與控制。
- `c99517e0`：修正 HTML 動態字串的引號，避免既有頁面 JavaScript 解析失敗。
- `8a15e005`：手牌卡按鈕 `data-art-id`，讓每張卡依兵種與階級持有穩定的美術資產 ID。

### B. 12 個兵種卡美術資產對應契約（**非 12 張完成的圖片**）

`docs/v2-unit-art-manifest.json` 建立 12 個固定 ID：步兵／刺客／魔法師／騎兵 × 初級／中級／高級，記錄正式顯示名稱、基礎戰力與國王傷害、兵種識別物、未來素材路徑。

**所有資產狀態均明確為 `NOT_IN_REPOSITORY`，`approved:false`**，未把文字或命名冒稱圖像已交付。美術原則遵循 `docs/v2-art-card-standard-v1.md` 第 9 節：每種兵種三張**不同人物**，保留共同的兵種識別，不自行創造能力文字。另以 `server/rules-v2-art-manifest.test.mjs` 驗證恰有 12 組唯一名稱與階級。

### C. 新增的實際 Chromium 驗收

新增 `tests/v2-tactics-browser.test.mjs`，使用兩個真實 Chromium 用戶端和 V2 Socket namespace：
1. 亞歷山大玩家透過新面板選擇兵種／敵人／直擊，對手選擇不保牌，驗證 HP 24→19、無原生對話框、他方手牌隱藏。
2. 成吉思汗玩家透過面板點選場上兵種與手牌，驗證交換、手牌與場上數量、能力次數。
3. 路易十四玩家先結束並回到自己回合，再透過面板犧牲場上兵種，驗證能力標記與場上兵種回收。

測試已納入 `.github/workflows/v2-rules.yml` 的 V2 網路工作流程；**新增測試、納入 CI 皆不等同已通過**。
