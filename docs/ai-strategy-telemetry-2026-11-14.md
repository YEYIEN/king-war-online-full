# 《國王戰爭》AI 進一步優化與遊戲平衡資料收集｜2026-11-14

## 執行狀態

本次修改位於 `feature/game-experience-redesign-20261114`（PR #5，**Draft / 未併入正式 main，也未部署 Render**）。

兩個實作方向：

1. **策略改善：** 成吉思汗 AI 撤回兵種不再無條件優先選高級騎兵，而是評估自己是否會暴露於反擊、手牌資源是否緊缺、撤回後場面是否崩潰。新舊 A/B 發現該策略在少人對局較有利，4、5人局應保留原策略。所有行為仍使用正常合法撤回機制，不向玩家提供提示或限制操作。
2. **資料記錄：** 建立與遊戲結算整合的低識別度 match telemetry，在真實對局結束（或房間中途放棄）後產生一次結構化摘要，另提供本地 JSONL 儲存與離線彙整工具。完整模擬仍使用原本獨立的 GitHub Actions JSON artifacts，不把 AI 模擬勝率當真人勝率。

## 已新增的資料欄位

每場只記錄**結果與匿名化行動統計**：

- `source`：`live`，與 `KW_SIMULATION=1` 的研究模擬分開
- `schemaVersion`、`rulesetId`：便於不同規則版本比較，避免混算
- `mode`：單人／多人／配對／教學；`playerCount`、`aiCount`、`humanCount`
- `aiDifficulty` 與各座位使用的 AI 難度
- `winnerSeat`、`winnerKing`、各座位國王及是否淘汰
- `turnsCompleted`、整場經過時間、每回合耗時（另外分真人與 AI）
- `finishReason`：正常結束、含投降／斷線、提前放棄
- `events`：部署、兵種攻擊、消滅／互換、攻擊國王及傷害、施法、撤回、逆轉技能
- `spells`、`spellsEffective`：各類魔法施放次數與**有造成可觀察場上狀態變化**的次數；後者**不代表實際戰術收益、也不能直接視為有效決策**
- `comeback`：一般與嚴格危機曾出現的合格對局，以及危機玩家是否最終獲勝

**不儲存：** 玩家名稱、遊戲房間代碼、IP、連線 socket ID、玩家 ID、重連 token、完整手牌、聊天紀錄、逐事件行動內容。資料雖不包含直接識別資訊，但仍有精確時間與少量對局屬性，應依照實際資料管理需求設定存取權限和保留期限，不能宣稱完全不可重新識別。

## 本地永久記錄與彙整方式

**預設不把真實對局資料寫入硬碟**，避免在未配置儲存空間、存取權限與留存政策時意外收集資料。部署管理者需要**明確啟用**：

```bash
# 建議位於 Web 靜態資源以外、且具有持久化儲存的目錄
KW_MATCH_METRICS_FILE=/var/data/kingwar/matches.match-metrics.jsonl
KW_RULESET_ID=ai-implicit-2026-11-14
```

啟用後，每一場有明確終局的真實對局會以獨立一行 JSON 寫入同一個檔案，場次放棄也會留下沒有勝者的紀錄。寫入序列化、失敗時只紀錄錯誤、不阻止玩家完成對局。**目前測試分支尚未部署，Render 沒有開始實際保存任何真人對局資料。**

若正式 Render 環境使用非持久化檔案系統，重啟／重新部署可能使本地資料遺失；需要確認儲存方案。不可使用 `client/dist` 或其他可公開下載的路徑保存資料。

在具有檔案存取權限的本地環境彙總：

```bash
node scripts/aggregate-match-metrics.mjs /var/data/kingwar/matches.match-metrics.jsonl > balance-summary.json
```

此腳本按「規則版本 × 對戰類型 × 人數 × AI 難度」分組，統計勝率、座位優勢、真人與電腦回合平均秒數、施法與可觀察狀態變更比例、行動次數、一般與嚴格翻盤率。**中途放棄場次不列入國王／座位勝率的完賽分母**；仍列入場次量與離局率。樣本數過低時應拒絕下強結論。

## 後續優化與資料治理

1. **先建立有效戰術事件定義：** 目前「魔法造成狀態變更」只是低階代理指標。下一版應衡量施法後是否真正清除守衛、打開國王攻擊路徑、延緩有效進攻，並避免把每一次掛上狀態都當作有效施法。
2. **建立 AI 決策實驗：** 固定一批合法場面，在相同情況下比較低／中／高／征服者的行動結果，避免僅以總勝率評價策略。
3. **分析人數×國王×難度交互作用：** 收集足夠多的真人對局後，與模擬分開分析；對樣本量與信賴區間加註。
4. **歷史資料保留與告知：** 正式啟用前確認資料保留期限、存取控制、玩家告知方式；持久化資料宜制定輪替與備份策略。只有規則版本一致的場次才適合直接彙總比較。
5. **不能自動認定玩家學會策略：** 勝率是競技輸贏指標，不直接測量玩家對規則、卡牌時機的理解。若要評估教學效果，須用不干預對局的事後檢視或可選研究方式。
