# 《國王戰爭》牌庫耗盡、戰鬥介面與新手實戰教學修正報告

**日期：2026-11-15｜測試分支：`fix/deck-ui-tutorial-redesign-20261115`｜Draft PR #9**

## 本次問題與處置

### 一、長局牌庫耗盡造成無法抽牌（已修改）
- **根因**：伺服器舊版 `drawUnits` 與 `drawMagic` 在牌庫長度為零時直接停止；消滅的兵種不會返回抽牌堆，因此長局可能完全停止取得新兵種。
- **修復**：新增共用 `server/deck-cycle.js`，牌堆空了就生成並隨機洗勻新一輪同配比卡牌，每張生成新的 ID；兵種及魔法抽牌均使用同一更新邏輯。原有抽牌數量、國王額外抽牌、手牌上限仍使用正式伺服器的原規則。
- **觀測**：`room.deckCycles` 記錄每種牌堆續輪次數，牌庫自動補充時寫入可見對局紀錄。保留舊手牌及場上牌，不會回收玩家持有的卡。
- **影響／風險**：這是**無限續輪資源機制**，不只是外觀補丁：長局卡牌供給增加，可能改變高資源國王及守備／快攻策略的相對強度。此做法與「先收集棄牌再重洗」不同。正式採納前應用長局測試觀察抽牌節奏和國王勝率，不應宣稱完全沒有平衡影響。
- **測試**：新測試驗證兵種／魔法牌堆在耗盡後重新建立、牌卡 ID 不重複、玩家持有的卡不被移除、循環計數與錯誤 deck key 保護；整合測試保護真正伺服器對戰操作。

### 二、戰鬥 UI 操作路徑太長且優先級不清（已重新安排）
- **舊版問題**：玩家須先越過敵方/我方場地才找到手牌；魔法按下後要在畫面遠端尋找施法步驟；狀態與下一步操作沒有清晰統一入口；選定攻擊者後也不易知道怎麼取消。
- **本次修改**：
  1. 新增「戰場指揮」狀態面板，明確顯示現在是誰的回合、我方可行動兵種數、下一步應做什麼。
  2. 手機及桌機先呈現手牌與部署，再進入目標玩家和兩邊戰場；以手牌／我方戰場／敵方戰場錨點快速跳轉。
  3. 選擇攻擊者後顯示其名稱與取消按鈕；敵方仍有步兵時，國王攻擊按鈕明示「步兵守衛中」。
  4. 魔法選施法者／目標／確認流程移到**手牌旁同一主要欄位**，避免被戰鬥紀錄推到整頁最下方。
  5. 新增響應式 CSS 與鍵盤焦點，不改變任何攻擊合法性或後端處理方式。
- **驗證**：新增 UI 靜態防呆、Node 測試、桌機/手機 Playwright 四種尺寸橫向溢出檢查；仍需真人實機對戰觀察操作時長及出錯率。

### 三、新手訓練不該使用選擇題（已重構）
- **舊版問題**：原先只有四個實際動作、完成後要求作答三題，且教學沒有直接示範如何攻擊國王、防守或跨回合決策。
- **本次設計原則**：移除全部問答測驗；只以**本人真正操作**而非回答或播放動畫作為完成條件，且由正式 Socket.IO 伺服器判斷操作是否合法。
- **兩回合、九步實作**：
  1. 從手牌部署中級騎兵；
  2. 由初級法師施放力量術強化騎兵；
  3. 選擇攻擊者消滅中級弓兵；
  4. 選初級騎兵直接攻擊沒有步兵防線的國王；
  5. 結束回合，觀察對手布下步兵守衛，開始下個回合與抽牌；
  6. 從手牌部署自己的中級步兵建立防線；
  7. 用重置行動的中級騎兵剋制並清除敵方初級步兵；
  8. 改用另一名可行動騎兵再次攻擊國王；
  9. 結束回合完成教學並返回主選單。
- **教學 UI**：以目前關卡、具體按卡/指定目標、原因、策略提醒及「前往操作區」按鈕，直接對照真正戰鬥版面；伺服器只有在操作成功後才更新進度。答案題庫、作答及成績提示皆已刪除。
- **測試**：新增九步 Socket.IO 完整整合測試，並修正舊的四步教學整合測試以覆蓋兩回合流程。
- **實際瀏覽器驗證**：Playwright 已從手機版教學首頁一路點到九步完成，包括部署確認、選法師、魔法目標及施放確認、兩次兵種／國王攻擊、跨回合防守與終局。這不是只測第一頁。
- **延伸學習（正式對局）**：戰場指揮面板新增「查看我的王權」實際按鈕，並依照遊戲狀態提示可操作的法師施法、弓兵特色、成吉思汗騎兵撤回及背水一戰；玩家可立即在自己的合法對局中試用，完全沒有測驗。
- **清楚的範圍限制**：九步涵蓋核心戰鬥介面、部署、施法、王傷、守衛、剋制、跨回合和抽牌，但**未將全部特殊國王被動、成吉思汗撤回、弓兵追加攻擊、背水一戰與 3–5 人目標選擇製成獨立實際練習關**。正式規則頁仍可查看，下一期應設計選修進階實戰章節，而不在教學後添加考卷。
