# 《國王戰爭》V2｜正式兵種卡牌美術規範 V1

**版本：** 2026-11-22  
**性質：** 視覺設計規範，不是新增／修改遊戲規則；尚無完成的正式卡圖。  
**依據：** 使用者提供之《國王戰爭》正式卡牌設計指令 V1，以下將其正式化並與 V2 既有資料相容。

## 一、作品定位

- 原創日系奇幻戰略收藏卡，**63 × 88 mm、直式 Full Art**；可實體印刷及數位遊戲展示。
- 融合清晰日式動漫人物、精緻二次元女性化角色魅力、半厚塗光影、王國／歷史戰爭／奇幻敘事；裝備必須維持兵種辨識度。
- PTCG AR／SR／SAR **僅供內部視覺層次及場景構圖參考**，不複製既有角色、卡框、圖示、品牌、排版或專有設計，且**絕不印 AR／SR／SAR 或稀有度標記**。
- 同系列一致：繁體中文、固定數值圖示與位置、一致資訊層級；角色姿勢／場景避免重複。沒有未經確認的額外費用、攻防屬性與能力。
- 美術與規則分離：視覺設定不得自行創造、修改戰力、傷害、能力或階級。

## 二、三個階級的視覺語言

| 正式遊戲階級 | 內部視覺參考 | 角色狀態及故事 | 構圖、裝備與光 |
|---|---|---|---|
| **初級** | AR 感 | 新兵、訓練、巡邏、上陣前；清新、親近 | 人物融入環境，簡潔裝備，柔和自然光，依然是完整高品質全圖 |
| **中級** | SR 感 | 具個性及實戰經驗的精銳 | 人物占比可提升，武器／盔甲細節、動態姿態和明確環境光 |
| **高級** | SAR 感 | 威望與使命感、強者的特殊身分 | 大場景敘事，戲劇化構圖、金屬與旗幟／魔法特效；高級感來自敘事而非單純更多亮光 |

**階級不是稀有度；美術品質不能讓初級卡顯得粗糙。**

## 三、正式資訊與 V2 資料來源

每張卡面至少有四個彼此獨立、可校對的文字／圖示區：

1. **名稱：** 正式兵種名稱及階級標示，文字繁體中文。
2. **戰力：** 獨立且固定位置的戰力圖示＋正式數值。
3. **對國王傷害：** 與戰力不同的圖示＋正式數值。
4. **兵種能力：** 逐字採用已核准規則文字；使用高對比半透明資訊底板／漸層，不讓角色與特效壓住文字。

現行 V2 基礎資料可供核對：初級／中級／高級，基本戰力 **1／2／3**、對國王基本傷害 **1／3／5**。本規範不授權自行增補每張卡的特殊能力；若該兵種沒有獨立能力，就只展示有正式依據的兵種克制／定位說明，且不可把通用克制偽裝為新能力。正式能力要以最新 V2 規則為準。

正式兵種顯示名稱：**步兵、刺客、魔法師、騎兵**。程式內舊代碼 `弓兵` 對應「刺客」，`法師` 對應「魔法師」；不能讓舊代碼出現在正式卡面。

## 四、分層製作要求

**A. 純插畫層（Full Art）**
- 只產出角色、武器、服裝、場景、旗幟、光影；**不烘焙正式數值、卡名、能力文字、圖示或稀有度**。
- 人物應適合 63 × 88 mm 直式裁切，重要五官和手持武器避開裁切安全區。
- 場景及角色依兵種區分，但整體色彩、質感與世界觀一致。

**B. 獨立資訊排版層**
- 使用程式或可編輯的排版來源添加繁體中文名稱、戰力、國王傷害及能力；不得僅交付不可編輯的合成圖片。
- UI 以固定欄位資料來源渲染，能力文字長時調整排版，不裁切、不縮到難以閱讀。
- 無底色遮擋的全圖卡面仍需保證文字對比；手機上優先讓數值與操作目標可辨識。

**C. 最終輸出及印刷**
- 完整尺寸 63 × 88 mm；出血與安全邊界依印刷廠提供規格，未取得規格時標為待確認，不臆造正式參數。
- 針對桌面與 320、375、390、430px 檢查縮小後辨識度。
- 記錄每項素材生成／來源、使用權限、版本、內容審核與是否正式定稿。

**正式規則資料不足時，僅能產出無正式數值的美術概念稿。**

## 六、正式執行與卡面驗收

1. 先讀取最新 V2 規則及遊戲程式資料，核對正式名稱、階級、數值與能力。
2. 先確認角色定位、故事性構圖、裝備與同系列風格。
3. **生成／繪製純 Full Art 插畫**（禁止在圖內生成正式文字），並交付可檢視檔案。
4. 實作**可編輯的獨立卡面資訊層**，以真實遊戲資料呈現四個資訊欄位。
5. 逐字與數值校對；檢查縮小辨識、對比、裁切；未通過退回修改。
6. 每張卡必須同時交付 **純插畫、含資訊卡面、資料／版本／審核紀錄**；完成圖像和排版驗收後才標記「正式」。

## 七、第六周目限定樣板任務（非全卡量產）

- 先選**同一兵種**各一張初級、中級、高級，共 **三張真正可觀看的全圖概念卡**；比較 AR／SR／SAR 感和兵種辨識度。
- 每張至少要有純插畫及獨立資訊合成預覽，不用正式稀有度字樣；若規則能力未確認，使用「能力內容待規則確認」的明確樣板標示，而非自創效果。
- 一位國王的立繪、選角卡、戰場資訊框屬 **另一套獨立樣板**，不得拿兵種三階卡替代。
- 不將文字規格、提示詞、空白框、預設 placeholder 當成已完成美術交付；必須有可供評估的實際圖像。

## 八、2026-11-22 已確定修訂：同一角色三階成長（優先採用）

**使用者正式選擇「角色成長型」而非「不同人物職階型」。** 對同一兵種初級／中級／高級三張卡，應當一眼看出是**同一位角色**經過成長，不是三個不相干的人，也不是同一張圖單純加光效。這是美術上的「進化感」，**不代表遊戲程式有進化、升級或稀有度機制**。

### 各兵種跨階級不變的識別核心

| 兵種 | 核心辨識物（初級就必須出現） | 初級 → 中級 → 高級的成長 |
|---|---|---|
| **步兵** | **盾牌**＋近戰武器；延續同一個盾徽／盾形輪廓 | 木／輕盾與實習劍士 → 金屬戰盾與守城精銳 → 強化大型盾與戰場統帥；盾牌不能被華麗裙裝或特效遮住 |
| **刺客** | **雙短刃或單柄可辨識匕首**，搭配延續的羽／影紋飾 | 入門輕裝與潛行 → 精準滲透的雙刃 → 高級隱密獵手，姿態、暗器與剪影成熟；不誤畫成弓兵 |
| **魔法師** | **施法法杖／法器**與可辨識的魔法紋樣 | 簡單媒介、初級小法陣 → 精工法杖、結構清晰的法陣 → 具辨識度的高階核心法器與大型結界；不用憑空新增遊戲法術效果 |
| **騎兵** | **坐騎（馬）＋騎槍／騎士武裝**，保留特定馬匹花色或馬具紋樣 | 初騎乘練習／輕裝 → 配合默契的騎士與戰馬 → 具統一標誌的重裝騎士與戰馬；人物與馬都不可被裁切成看不出騎兵 |

- 每個角色先設定**不可變的身分錨點**：例如髮色／瞳色、髮飾、武器／防具上的徽記與關鍵形狀，再設計可成長的部分（髮型變化、表情成熟、武器尺寸、護具、姿態、場景故事）。
- 三階要讓玩家透過**黑色剪影、兵種裝備、場景敘事**就能辨識；不是只換服裝配色或靠加強發光特效區分。
- 角色故事可以是「第一次出征 → 關鍵守城戰 → 帶領軍團」，不同兵種另有相符的情節（刺客潛入任務、魔法師研究／結界、騎兵馳援／衝鋒）。
- 這四類識別符號用於 UI、卡牌及未來美術量產，不得在缺少資料時創造正式兵種能力與新的額外屬性。

### 已確認的卡面呈現

- 角色畫幅**大、聚焦角色**，全圖插畫不可被文字區塊吃掉半張。
- 使用 **frosted glass / backdrop blur** 的半透明資訊區（名稱、戰力、國王傷害、能力），維持人物視覺完整和文字對比；這是**畫面效果參考**，不是照抄任何特定 TCG 卡框。
- 正式製作流程仍是**無文字原畫 + 可編輯的資訊／圖示層**；即使概念圖內含 AI 生成文字，也必須逐字核對並在正式檔由獨立資訊層重做。
- 美術樣板保留正式遊戲名稱「初級步兵／中級步兵／高級步兵」；進化式敘事稱號（例如見習、精銳、統帥）只可作為內部人物設定或已核准的副標題，不可自行取代遊戲內兵種名稱。
- **必須先交人物設定與三階視覺驗收，再批量生成**；形象連續性、兵種辨識、卡面數值、素材授權、可讀性各自獨立驗收。
